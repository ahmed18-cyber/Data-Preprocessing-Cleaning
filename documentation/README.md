# Project Documentation

This directory contains the technical documentation for the Data Preprocessing & Cleaning Web Application.

## Documentation Structure

| Document | Description |
|---|---|
| `phase1_ingestion.md` | Documents dataset ingestion, supported file formats, session management, Parquet storage, dataset configuration, and preview functionality. |

## Project Architecture

The application is organized into two main components:

- **Frontend:** React, TypeScript, and Vite application.
- **Backend:** FastAPI application responsible for data ingestion, exploratory data analysis, preprocessing recommendations, transformations, and exports.

## Additional References

- **API documentation:** Available through FastAPI Swagger UI at `http://localhost:8000/docs` while the backend is running.
- **Main project guide:** See the root `README.md` for installation, configuration, execution, and testing instructions.
